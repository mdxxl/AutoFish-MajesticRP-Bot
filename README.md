# Majestic RP Fishing Bot

Бот для рыбалки в Majestic RP. Сам забрасывает удочку, следит за поплавком и вываживает рыбу. Улов можно забирать или отпускать ради бонуса EXP — режим переключается на F9.

Бот ориентируется по изображению на экране. Состояние, статистика и журнал работы видны в оверлее. Есть и авто-пауза: бот останавливается, если меню снаряжения пропадает.

## Установка и запуск

Нужны Windows 10/11 и Python 3.10 или новее.

Откройте терминал в папке проекта и установите зависимости:

```powershell
py -m pip install numpy opencv-python mss keyboard PyQt6
```

Затем запустите бота:

```powershell
py start.py
```

Можно также дважды нажать на `start.bat`. Если оверлей не нужен:

```powershell
py main.py --no-gui
```

При запуске программа может запросить права администратора — они нужны для управления клавишами в игре.

## Перед первой рыбалкой

Сохранённые настройки рассчитаны на **2560 × 1440 (QHD)**. Если у вас другое разрешение, настройте области заново.

Откройте игру и по очереди укажите, где находятся меню снаряжения, шкала заброса, поплавок и кнопки в окне улова. Для этого используйте горячие клавиши из таблицы ниже. Нужный элемент должен быть виден на экране во время настройки.

Области выделяются рамкой мышью. Для отслеживания движения камеры на F12 рекомендуется выбрать область слева от логотипа игры.

Когда всё настроено, нажмите **F5**, чтобы начать. Эта же клавиша ставит бота на паузу.

## Управление

| Клавиша | Что делает |
| --- | --- |
| `F4` | Настройка области меню снаряжения для авто-паузы |
| `F5` | Старт / пауза |
| `F6` | Выход из бота |
| `F7` | Настройка области шкалы заброса |
| `F8` | Настройка области поплавка |
| `F9` | Переключение режима: забирать или отпускать рыбу |
| `F10` | Настройка кнопок в окне улова |
| `F11` | Показать / скрыть окно отладки |
| `F12` | Настройка области для отслеживания движения камеры |

## Где хранятся настройки

Бот сохраняет настройки в папке `core/`. После выбора областей файлы обновляются автоматически, поэтому вручную менять JSON обычно не нужно.

| Файл | Настройки |
| --- | --- |
| `menu_roi_config.json` | Область меню снаряжения для авто-паузы |
| `roi_config.json` | Область шкалы заброса |
| `bobber_config.json` | Область поплавка |
| `fish_action_config.json` | Кнопки «забрать» и «отпустить», область окна улова |
| `cam_roi_config.json` | Область для отслеживания движения камеры |
| `overlay_config.json` | Положение и отображение оверлея |

## Файлы проекта

Основная логика рыбалки и обработка изображения находятся в `main.py`. `start.py` и `start.bat` используются для запуска.

В папке `core/` лежат оверлей (`overlay.py`), фоновый поток бота (`bot_worker.py`), связь между ботом и интерфейсом (`bot_bridge.py`), инструменты выбора областей (`select_*.py`) и сохранённые настройки.
