# 🎣 Majestic RP Fishing Bot

Автоматический помощник для рыбалки в **Majestic RP**. Бот анализирует изображение игры, проходит этапы заброса и вываживания, выбирает действие с уловом и показывает состояние в компактном оверлее.

> Проект предназначен для Windows и Python 3.10+. Используйте его с учётом правил сервера Majestic RP.

## Возможности

- 🎯 Распознаёт шкалу заброса и помогает попасть в нужный сектор.
- 🫧 Следит за поплавком и определяет поклёвку.
- 🐟 Отслеживает движение камеры во время вываживания.
- 🧺 Выбирает, забрать рыбу или отпустить её ради бонуса EX.
- ⏸️ Может автоматически ставиться на паузу, когда меню снаряжения исчезает.
- 🖥️ Показывает состояние, статистику и журнал в экранном оверлее.
- ⚙️ Позволяет настраивать игровые области мышью; настройки сохраняются в `core/`.

## Требования

- Windows 10/11
- Python 3.10 или новее
- Запущенная игра Majestic RP
- Библиотеки Python: `numpy`, `opencv-python`, `mss`, `keyboard`, `PyQt6`

Установите зависимости в терминале VS Code:

```powershell
py -m pip install numpy opencv-python mss keyboard PyQt6
```

## Запуск

Откройте папку проекта в VS Code и выполните в терминале:

```powershell
py start.py
```

Либо запустите `start.bat` двойным щелчком. Для запуска без графического оверлея:

```powershell
py main.py --no-gui
```

Программа может запросить права администратора: они нужны для управления клавишами в игре. После запуска настройте игровые области и нажмите **F5**, чтобы начать работу.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `F4` | Выбрать область меню снаряжения для авто-паузы |
| `F5` | Старт / пауза |
| `F6` | Завершить работу |
| `F7` | Выбрать область шкалы заброса |
| `F8` | Выбрать область поплавка |
| `F9` | Переключить режим: забрать / отпустить рыбу |
| `F10` | Выбрать кнопки в окне улова |
| `F11` | Показать / скрыть окно отладки |
| `F12` | Выбрать область для отслеживания движения камеры |

Области выбираются перетаскиванием рамки мышью. Калибровку удобно проводить при открытой игре и видимых соответствующих игровых элементах. Координаты областей и параметры оверлея хранятся в JSON-файлах внутри `core/`.

## Как устроен проект

```text
.
├── main.py                 # логика рыбалки и обработка изображения
├── start.py                # точка запуска
├── start.bat               # запуск из Windows
└── core/
    ├── overlay.py          # экранный оверлей
    ├── bot_worker.py       # фоновый поток бота
    ├── bot_bridge.py       # связь интерфейса и бота
    ├── select_*.py         # калибровка игровых областей
    └── *_config.json       # сохранённые настройки
```

## Подключение проекта к GitHub через VS Code

### 1. Установите Git и войдите в GitHub

Если Git ещё не установлен, скачайте его с [git-scm.com](https://git-scm.com/download/win) и перезапустите VS Code. В VS Code откройте меню **Accounts** (иконка профиля) → **Sign in with GitHub** и завершите авторизацию в браузере.

### 2. Инициализируйте репозиторий

Откройте папку бота в VS Code. Перейдите в **Source Control** (`Ctrl+Shift+G`) и нажмите **Initialize Repository**. Если кнопки нет, откройте встроенный терминал в папке проекта и выполните:

```powershell
git init
git add .
git commit -m "Первый коммит"
```

Если Git попросит указать автора коммитов, настройте имя и почту:

```powershell
git config --global user.name "Ваше имя"
git config --global user.email "почта@example.com"
```

### 3. Создайте репозиторий на GitHub и опубликуйте проект

На [github.com/new](https://github.com/new) создайте новый репозиторий. Для уже существующей локальной истории удобнее оставить репозиторий пустым: не добавлять README, `.gitignore` или лицензию на сайте.

В VS Code нажмите **Publish to GitHub** в панели Source Control и выберите публичный или приватный репозиторий. Либо привяжите созданный репозиторий в терминале:

```powershell
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
git branch -M main
git push -u origin main
```

### 4. Выкладывайте последующие изменения

После редактирования откройте Source Control, проверьте список изменений, введите короткое описание в поле сообщения и нажмите **Commit**, затем **Sync Changes** (или **Push**). В терминале те же действия выглядят так:

```powershell
git add .
git commit -m "Кратко описать изменения"
git push
```

## Важно перед публикацией

Проверьте, что в настройках и исходниках нет токенов, паролей и личных данных. JSON-файлы в `core/` содержат координаты экрана и параметры калибровки — решите, хотите ли вы публиковать свои настройки. Перед публичной публикацией удалите или замените личные координаты и игровые скриншоты, если они появятся в проекте.
